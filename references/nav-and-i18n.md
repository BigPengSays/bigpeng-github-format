# 锚点导航与语言

Hero 导航的设计流程见 **[nav-design.md](nav-design.md)**（必读）。内容润色见 **[content-polish.md](content-polish.md)**。

## 两步分工

| 步骤 | 导航 | 内容 |
|------|------|------|
| **第一步** | 定 `##` + 填导航**草案** | 规划版块、映射节名 |
| **第二步** | **验证 href** → 写 Hero HTML | 润色各节，确保通顺 |

## 语言规则

导航**显示文字**跟随 README 主语言：

| README 主语言 | 导航标签 |
|---------------|----------|
| 中文 | 为什么 · 公式 · 用法 · 安装 · FAQ · 示例 |
| 英文 | Why · Features · Usage · Install · FAQ · Examples |

**不要**中文正文配纯英文导航项，除非用户要求双语。

## 必进导航的槽位

| 槽位 | 条件 |
|------|------|
| **Why** | **始终进导航** |
| Usage | 有用法内容时进 |
| Install | 有安装命令时进 |
| Features | 有功能/公式/特性节时进，标签用短名 |
| FAQ | 有边界/常见问题节时进 |
| Examples | 有 `examples/` 等文件时可进（外链） |

License、Star History **不进** Hero 导航。

## 增删原则

| 情况 | 做法 |
|------|------|
| **无 README** | **经典全套生成**并进导航（Why/功能/用法/安装/FAQ/结构）；见 no-readme-scaffold.md |
| 有 README、映射到标准槽 | **保留内容**；节名可规范化 |
| 有 README、项目独有节 | **保留原 `##` 名**；导航用短标签 |
| 原文无 Why | **必补** Why 节 + 导航项 |
| 想进导航的节 | **必须有 `##`**，不能仅 `<details>` |

## 默认不加 Star History

Star History 不进导航、不进正文（除非用户要求）；模板放「待你补充」。
