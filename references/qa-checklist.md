# 发出前检查

## 第一步：版块规划

- [ ] 已判断输入模式（有 README / 无 README）
- [ ] **有 README**：已盘点全部 `##`，原有重要版块已保留
- [ ] **无 README**：经典全套已生成（Why / Features / Usage / Install / FAQ / 仓库结构 / License）
- [ ] **无 README**：FAQ 至少 3 条问答；信息缺口已列进「待你补充」
- [ ] 存在 `## 🤔 为什么` 或 `## 🤔 Why`（必选）
- [ ] Usage / Install / FAQ 有对应内容时已映射
- [ ] 项目独有节（如公式表）仍在
- [ ] 已填导航**草案**（标签 → ## 标题 → 预计 href）

## 第二步：锚点 + 内容

### 锚点可跳转（关键）

- [ ] 已按**定稿 `##`** 重算 href，填完整核对表
- [ ] **每个** `#anchor` 都有对应 `##`（外链文件除外）
- [ ] **无**仅 `<details>` 无 `##` 却出现在导航的项
- [ ] 已删除失效项（如指向不存在 `#仓库结构` 的「结构」）
- [ ] Hero 导航在锚点验证**通过后**才写入
- [ ] 导航语言与 README 主语言一致
- [ ] Hero 导航含 Why/为什么 项

### 内容通顺

- [ ] Why 独立可读，有痛点/边界，不与 tagline 整段重复
- [ ] FAQ 为问答体，非边界 bullet 原样粘贴
- [ ] Usage / Install 有引导句，与前后节衔接
- [ ] 迁移/合并后的各节逐节朗读通顺
- [ ] **有 README**：H1 与原文一致（非 repo slug）
- [ ] **无 README**：H1 为自然语言产品名，并注明推断来源
- [ ] 原表格、代码块、链接未丢

## 其他

- [ ] Banner 仅有图时存在
